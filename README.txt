PORTFOLIO AMADOU BA
====================

Fichiers :
- index.html : contenu du site
- style.css  : design
- script.js  : bouton mode sombre

POUR LE METTRE EN LIGNE
1. Ouvrir index.html pour tester le site sur ordinateur.
2. Acheter éventuellement un domaine, par exemple amadouba.org.
3. Héberger les 3 fichiers sur un service comme GitHub Pages, Netlify ou un hébergeur classique.
4. Modifier les textes, ajouter une photo si souhaité et ajouter le PDF du CV.

Le design est inspiré de la structure générale d'un portfolio personnel moderne :
navigation simple, grande introduction, projets, compétences, parcours et contact.
Il ne reprend pas le contenu personnel du site de référence.
